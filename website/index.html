Cara Penggunaan & Instalasi

Pilih panduan di bawah untuk melihat langkah instalasi, pintasan tombol, konfigurasi, dan arsitektur.

🚀 Instalasi Otomatis (Satu Baris Perintah)

Cukup jalankan perintah berikut di terminal Linux kamu. Skrip ini akan memeriksa dependensi, membuat symlink ke Quickshell, dan mengonfigurasi autostart:

curl -sSL https://raw.githubusercontent.com/putrarawr/KuroNotch/main/scripts/install.sh | bash

Integrasi dengan Caelestia Shell (Jika Memakai)

Jika kamu sudah memasang Caelestia, gunakan skrip integrasi agar notification server tidak bentrok:

~/.config/quickshell/island-notch/scripts/install-integration.sh

⌨️ Perintah CLI & Integrasi Hyprland Binding

Kamu bisa memanggil Kuro Island melalui baris perintah atau menetapkannya ke hotkey di hyprland.conf:

# Tambahkan baris ini di ~/.config/hypr/hyprland.conf:

# Buka/tutup notch dengan Super + I
bind = $mainMod, I, exec, island-notch --toggle

# Langsung lompat ke halaman musik (page 0)
bind = $mainMod, M, exec, island-notch --page 0

# Suruh maskot Kuro menyapa / melambaikan tangan!
bind = $mainMod SHIFT, W, exec, island-notch --wave

⚙️ Konfigurasi JSON

Konfigurasi disimpan di berkas ~/.config/island-notch/config.json. Kamu bisa mengubahnya lewat modal pengaturan di notch atau mengedit berkasnya langsung:

{
  "preset": "notch",          // Pilihan: "notch", "pill", "strip"
  "palette": "obsidian",       // Pilihan: "obsidian", "midnight", "forest", "crimson", "amber", "violet"
  "adaptiveGlow": true,        // Aksen warna berpendar sesuai cover album lagu
  "pomodoro": {
    "focusMin": 50,
    "breakMin": 10,
    "chimeEnabled": true
  },
  "lyrics": {
    "enabled": true,
    "showInCollapsed": true
  },
  "companion": {
    "enabled": true,
    "waving": true
  }
}
TANYA JAWAB

Pertanyaan yang Sering Diajukan

Apakah harus menggunakan Caelestia untuk menjalankan Kuro Island?

Tidak! Kuro Island sepenuhnya mandiri (standalone). Kamu hanya membutuhkan Linux dengan Hyprland dan Quickshell 0.3.1. Namun jika kamu pengguna Caelestia, skrip integrasi kami sudah menyediakan penyesuaian otomatis agar tidak bentrok.

Apakah lirik lagu mendukung pemutar selain Spotify?

Ya! Semua pemutar yang mendukung standar MPRIS Linux (seperti Spotify, Cmus, MPD, Firefox, Chromium) didukung. Berkas lirik format LRC otomatis di-cache di ~/.cache/island-notch/lyrics/.

Berapa konsumsi daya dan memori Kuro Island?

Sangat ringan. Berkat arsitektur event-driven berbasis soket C++ Quickshell tanpa polling loop, konsumsi RAM hanya ~45–60 MB dan CPU 0.0% saat idle.
